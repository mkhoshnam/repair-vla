Can a frozen Vision-Language-Action model adapt to physical robot faults using task reward alone, without fault demonstrations, reference trajectories, or explicit fault labels?

REPAIR architecture

Frozen foundation policy The VLA remains unchanged; adaptation is performed by a lightweight residual controller.
Fault-agnostic recovery A shared policy must infer altered robot capability from execution feedback instead of receiving a fault label.
Task-reward-only learning Recovery is learned from task success without healthy reference trajectories or fault demonstrations.

Approach

Frozen Vision-Language-Action policy

A pretrained VLA provides the base manipulation action and remains frozen throughout adaptation.

Shared fault-agnostic residual policy

A single residual reinforcement-learning policy is trained across multiple physical fault conditions. Fault identity is not provided to the policy.

Execution-feedback conditioning

The residual policy uses proprioception and recent commanded-versus-realized motion history to infer when the robot is no longer responding as expected.

Task-reward-only adaptation

The learning signal is task success. The method does not require fault demonstrations, nominal reference trajectories, or supervised fault labels.
