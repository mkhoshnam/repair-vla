A capability-aware residual policy adapts a pretrained robot policy to physical impairments using task reward and execution feedback.

REPAIR pipeline

From task execution to capability inference and corrective control.

1. Task policy acts The pretrained VLA proposes the task-directed action from the current observation.
2. Physical response is observed The robot may realize the commanded motion differently when its capability changes.
3. Capability is inferred A shared per-actuator encoder combines execution history with current kinematic information.
4. Information is composed Cross-actuator attention builds a compact representation of the robot's current capability.
5. Control is corrected Reinforcement learning produces a bounded residual correction that is added to the base action.

Approach

Capability-aware adaptation

REPAIR uses recent execution history to infer how the robot's effective physical capability has changed during task execution.

Shared capability representation

The same temporal encoder is applied across actuators, while current kinematic information grounds each local capability representation in its geometric effect on robot motion. Cross-actuator attention then forms a global capability state.

Residual reinforcement learning

The inferred capability state conditions a residual reinforcement-learning controller that adapts the task-directed base action using task reward.

Generalization

The method is designed to transfer to held-out physical faults by reusing the same capability encoder and grounding mechanism rather than relying on explicit fault identity.
